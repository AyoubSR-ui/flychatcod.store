  ? activeProducts

          ? ` | Variants: ${p.variants.join(", ")}`

Helper for phone normalization

Use a simple safe normalization first.

function normalizePhone(phone?: string | null): string | null {
  if (!phone) return null;
  const normalized = phone.replace(/[^\d+]/g, "").trim();
  return normalized || null;
}
Normalize before lookup
const normalizedPhone = normalizePhone(conv?.customerPhone);
Query recent orders

8. Use better message mapping for the model

When converting DB messages to OpenAI messages, keep roles clean.

Example
const aiMessages = [
  { role: "system", content: systemPrompt },
  ...historyForAi
    .filter((m) => m.content && m.content.trim().length > 0)
    .map((m) => ({
      role:
        m.sender === "customer"
          ? "user"
          : "assistant",
      content: m.content,
    })),
];

That ensures:

customer → user

agent/bot/AI → assistant
