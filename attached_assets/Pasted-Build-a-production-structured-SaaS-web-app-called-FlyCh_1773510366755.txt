Build a production-structured SaaS web app called “FlyChat COD” for ecommerce sellers in COD-heavy markets like Algeria.

PRODUCT VISION
FlyChat COD is not just a support chat tool. It is a chat-to-order SaaS platform that helps merchants turn website chats into structured cash-on-delivery orders. It includes a seller dashboard, realtime inbox, order capture workflow, customer CRM, team-ready architecture, future omnichannel channel integrations, and optional AI automation later.

TARGET MARKET
- Primary launch market: Algeria
- Expansion-ready for Morocco, Tunisia, and other French-speaking / COD-heavy markets
- Main users: ecommerce sellers, COD stores, small businesses, support/sales teams

CORE VALUE PROPOSITION
- Turn chats into confirmed COD orders
- Reduce manual order handling
- Organize customer conversations and orders in one place
- Prepare the business for future WhatsApp, Instagram, and Messenger integration
- Support bilingual operation in English and French from day one

TECH STACK REQUIREMENTS
- Use Next.js with App Router
- Use TypeScript
- Use Tailwind CSS
- Use PostgreSQL
- Use Prisma ORM
- Use Socket.IO or equivalent realtime architecture for live chat updates
- Build reusable components and modular code structure
- Use environment variables for secrets
- Include seed/demo data for testing
- Include a clean README with setup instructions
- Generate a codebase that is realistic, scalable, and honestly scaffolded where external integrations are not yet live

INTERNATIONALIZATION REQUIREMENTS
This SaaS must support 2 full interface languages from day one:
- English
- French

Implement proper i18n architecture across the entire app:
- no hardcoded user-facing text
- use translation files/dictionaries for all UI labels, buttons, headings, forms, statuses, and helper text
- use English as fallback locale
- add a language switcher on the public website and inside the authenticated dashboard
- store the user preferred language in the database
- store the store-level default widget language in the database
- the embeddable widget must support English and French UI labels and greetings
