--------------------------------------------------

REQUIRED LANGUAGE BEHAVIOR

- If visitor writes in Algerian Darija / Arabic → reply in Arabic/Darija

- Do not default to English when the user is clearly speaking French or Darija
- Do not reply bilingually by default

1. locked conversation language if already established
2. otherwise detect from the first meaningful customer message
3. later messages may continue that language

5. widgetLanguage is fallback only, not the main decision source
