5. Do NOT switch language randomly on later turns unless the customer clearly changes language and the system explicitly allows it

IMPORTANT RULE
The AI should not choose language based only on the latest message every time.
The language should be anchored from the first meaningful customer message and remain stable for the conversation unless there is a clear intentional language switch.
