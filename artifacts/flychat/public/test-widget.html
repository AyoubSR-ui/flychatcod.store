FlyChat Widget Test Page

This page embeds the FlyChat chat widget for testing purposes. If the widget is configured correctly, you should see a floating chat button in the bottom-right corner.

How to test

  1. Log in to the dashboard with demo@flychat.dz / demo123456
  2. Go to Widget settings and copy your store ID from the embed snippet
  3. Replace the storeId value below with your actual store ID
  4. Open this page and click the chat button
  5. Send a message, then check your Inbox to see it
Note: Replace YOUR_STORE_ID_HERE in the script below with your actual store ID from the Widget settings page.
