FlyChat Widget Test Page

This page embeds the FlyChat chat widget for testing. You should see a floating chat button in the bottom-right corner.

Local Testing (same-origin)

  1. Make sure the API server and frontend are running.
  2. Open this page at /test-widget.html in the preview.
  3. Click the blue chat button in the bottom-right corner.
  4. Send a message in the chat window.
  5. Log in to the dashboard (demo@flychat.dz / demo123456) and open Inbox — your message should appear.

External Testing (third-party site)

  1. Log in to the dashboard and go to the Widget > Installation tab.
  2. Copy the embed snippet — it includes the full absolute URL to widget.js.
  3. Paste the snippet into your external HTML page before </body>.
  4. Open that page — the chat button should load and connect back to your FlyChat instance.
Note: The storeId below is pre-filled with the seeded demo store. To use a different store, replace the value in FLYCHAT_CONFIG.
